# OperaDash

Extensão Chrome para análise operacional de alarmes, disponibilidade, chamados ITSM e inventário a partir de planilhas Excel. A extensão processa os arquivos no navegador e oferece filtros, indicadores, rankings e comparações mensais.

## Instalar

1. Baixe ou clone o repositório.
2. Abra `chrome://extensions`, ative o **Modo do desenvolvedor** e clique em **Carregar sem compactação**.
3. Selecione a pasta [`operadash-extension`](operadash-extension), que contém o [manifesto](operadash-extension/manifest.json).
4. Abra a extensão pelo ícone do Chrome e importe os arquivos na seção **Arquivos e IA**. Confira os cabeçalhos identificados e as colunas associadas a cada indicador.

## Assistente de análise

O painel funciona localmente. Para usar o assistente, selecione um provedor e autorize o acesso solicitado pela extensão. O [guia da extensão](operadash-extension/README.md) detalha a configuração de serviços locais e online, as permissões e o tratamento dos dados.
